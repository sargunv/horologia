# Horologia mobile

The Expo application for iPhone, iPad, Apple-silicon Macs through iPad compatibility, and adaptive
Android devices.

Use the repository tasks:

- `mise run //clients/mobile:dev`
- `mise run //clients/mobile:ios`
- `mise run //clients/mobile:android`
- `mise run //clients/mobile:generate`
- `mise run //clients/mobile:check`
- `mise run //clients/mobile:test`

Widget changes require native iOS and Android builds. Launcher placement is verified manually.
